# Выполнение кода в гостевой macOS

Решение выбрано владельцем проекта: команды Java/Gradle и Swift/Xcode выполняются в виртуальной машине. App Sandbox основного приложения остаётся включённым. Старый runner с вложенным sandbox-exec удалён: проверка на этом Mac показала `sandbox_apply: Operation not permitted`.

## Компоненты

- `ProcessGateway` — граница приложения Java: рабочая область, разрешённые пути, программа, аргументы, таймаут и отмена.
- `VirtualMachineProcessGateway` — сохраняет запрос, ждёт гостевой результат, проверяет перенос файлов.
- `VmWorkspaceTransfer` — копирует обычные файлы без Git и ссылок. Проверяет размер, хеши и конкурентные пользовательские изменения. Возвращает только файлы разрешённых путей.
- `MacPlatformBroker` — закрытые унаследованные pipes между приложением и его Java-процессом. Публичного HTTP метода запуска VM нет.
- `VirtualMachineExecution` — копирует базовый диск и NVRAM, запускает VM, ожидает результат и полностью останавливает гостя перед чтением результатов.
- `VirtualMachinePreparation` и экран Environments — установка macOS из IPSW и ручная подготовка инструментов.
- `native/GuestRunner` — отдельный бинарник и launch daemon внутри гостевой системы.

Для команд VM не имеет сетевого устройства. Общая папка содержит только staging задания, без `.git`, Keychain, БД, исходного репозитория и настроек приложения. Образ копируется на каждую команду; изменения гостевой ОС не переживают её завершение. Во время ручной подготовки разрешён NAT, чтобы владелец мог установить зависимости. Агент этот режим включать не может.

## Подготовка владельцем Mac

1. После настройки сертификата Apple с приватным ключом задать `BLOT_SIGNING_IDENTITY` и собрать приложение через `script/build_and_run.sh`: упаковка добавит JVM и гостевой runner. Запуск установленного приложения пока отложен владельцем проекта; сборки без запуска проверяются отдельно.
2. Открыть Settings → Environments → «Установить из IPSW…». Выбрать совместимый локальный образ macOS для Apple Silicon. Blot не скачивает большой IPSW автоматически.
3. Дождаться установки, затем открыть «Подготовить инструменты».
4. Завершить Setup Assistant гостевой macOS. Не подключать личные аккаунты и секреты.
5. В гостевом Terminal выполнить:

   ```sh
   sudo sh '/Volumes/My Shared Files/bootstrap/install-guest.sh'
   ```

6. Установить JDK 25 в `/Library/Java/JavaVirtualMachines/blot/Contents/Home`; установить Xcode, принять лицензию и выбрать его developer directory.
7. Подготовить необходимые зависимости проектов в гостевых кэшах. При агентном запуске сеть выключена; отсутствующая зависимость должна приводить к настоящей ошибке сборки.
8. Закрыть гостевые приложения и нажать «Сохранить образ». Blot запрашивает штатное завершение macOS и сохраняет маркер только после остановки.
9. Проверить реальное задание каждого поддерживаемого профиля. Наличие маркера образа само по себе не подтверждает готовность runner или установленных инструментов.

Начальные ресурсы: до 4 CPU, 8 ГБ RAM, разреженный диск 128 ГБ. Для APFS копия диска обычно использует copy-on-write. Точное потребление зависит от образа и файловой системы.

## Данные задания

Java создаёт `vm/jobs/<UUID>/request.json` и `workspace`. Mac передаёт в VM только каталог `exchange`: запрос и рабочие файлы. Гость создаёт `result.json` с тем же ID, кодом завершения, ограниченным выводом и признаком обрезки. Ответ гостя считается недоверенными данными.

Отмена или таймаут останавливают VM. Ошибка остановки блокирует освобождение каталога и следующий запуск. Результат импортируется после полной остановки и проверки файлов. Несколько изменений импортируются отдельными атомарными заменами; сбой между заменами остаётся UNKNOWN и требует сверки, а не автоматического повторения.

Лимиты переноса первой реализации: 20 000 файлов, 32 MiB на файл, 256 MiB на задание. Символические ссылки не поддерживаются. `.git`, `.build`, `.gradle`, `build`, `DerivedData`, `node_modules` не переносятся; гостевые кэши готовятся отдельно. Эти ограничения возвращают явные ошибки.

## Что проверено

Swift-код хоста и гостевого бинарника собирается. Java-проверки проверяют исключение Git, запрет ссылок, область импорта и обнаружение конкурентных изменений. Реальная VM пока не прошла приёмку: установленного базового образа с JDK/Xcode в этой рабочей среде нет.

Официальные основания: [macOS VM на Apple Silicon](https://developer.apple.com/documentation/virtualization/running-macos-in-a-virtual-machine-on-apple-silicon), [общие папки](https://developer.apple.com/documentation/virtualization/shared-directories), [entitlement Virtualization](https://developer.apple.com/documentation/virtualization/adding-the-virtualization-entitlement-to-your-project).
