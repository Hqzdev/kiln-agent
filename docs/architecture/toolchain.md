# Архитектура: версии инструментов и библиотек

Задача: A2.6. Дата: 11 октября 2026. Документы и настройки подготовлены; задача целиком требует реализации пользователя.

## Что подготовлено без кода приложения

В toolchain.lock.json записаны Temurin 25.0.4.1+1, Gradle 9.1.0, Xcode 27.0 (27A5252f), Swift 6.4 и минимальные ОС 26.0. SHA-256 для JDK и Gradle сохранены. В каталоге Gradle закреплены Spring Boot 4.1.1, SQLite JDBC 3.53.4.0, Jackson, JUnit и Spotless. Сохранены lock-файлы и verification-metadata.xml. В пакеты Swift внешние библиотеки пока не входят. Полная повторяемость продукта, встроенная Java выпуска и совместимость настоящего провайдера проверяются после пользовательской реализации.

Статус Java 25 как LTS указан в [плане Oracle](https://www.oracle.com/java/technologies/java-se-support-roadmap.html). Совместимость конкретного выпуска Spring Boot нужно сверять с его [системными требованиями](https://docs.spring.io/spring-boot/system-requirements.html). Точные версии исправлений Spring, Gradle и SDK нельзя считать установленными до создания модулей и пробной сборки.

## Версии существующего сайта

Сайт использует Next.js 16.4.0, React 19.3.0 и зависимости из package.json/package-lock.json. Это версии сайта для работы с планом. Они не описывают среду Swift или Java будущего продукта.

## Протокол сборки

Список параметров сборки (`manifest`) должен содержать:

- commit SHA и признак несохранённых изменений;
- поставщика JDK, версию и контрольную сумму;
- версии Gradle и Swift;
- версию и номер сборки Xcode;
- целевой SDK и минимальные версии систем;
- версии структуры базы сервера и схемы API.

Значения получают командами инструментов. Запись «latest» не позволяет повторить сборку и не подходит.

При подготовке поставки нужно выбрать поставщика встроенной Java и зафиксировать официальные условия её распространения. В репозитории сохраняются сведения о происхождении дистрибутива и положенные уведомления.

## Когда A2.6 можно закрыть

После создания целей сборки нужно закрепить точные версии, Wrapper, контрольные суммы и файлы фиксации зависимостей. Затем собрать Java, Mac и iOS из чистой копии репозитория и сохранить протокол. До этого задача остаётся запланированной, хотя документ готов.
