## Commands and observed results

From the repository root, with JDK 25 selected:

```sh
scripts/check-backend.sh
```

The script runs Gradle projects, strict dependency verification, spotlessCheck,
check and bootJar, then swift build/test for BlotDomain and BlotAPI. Java HTTP
tests write project/run/specification/task responses to `.build/http-fixtures`.
The script passes this directory through BLOT_HTTP_FIXTURES to Swift tests.

Local JDK selection for the recorded run:

```sh
JAVA_HOME="$PWD/.build/tools/jdk-25.0.4.1+1/Contents/Home" \
GRADLE_USER_HOME="$PWD/.build/gradle-home" scripts/check-backend.sh
```

The full script completed successfully. Gradle 9.1.0 used Java toolchain 25;
all four modules configured; 14 Java tests passed (7 application, 3 storage,
4 API). The runnable bootJar was built. No dependency was added, so existing
lock files and verification metadata passed unchanged under strict verification.

After the final Swift envelope encoding corrections:

```sh
BLOT_HTTP_FIXTURES="$PWD/.build/http-fixtures" swift test --package-path packages/BlotAPI
```

Result: 10 tests passed, including exact golden command structure, explicit
nullable runId, version rejection and decoding actual HTTP responses. BlotDomain
has 2 passing tests. Local compiler: Apple Swift 6.4, Xcode beta/macOS SDK 27;
manifests require Swift tools 6.2 and macOS/iOS 26. CI explicitly selects Xcode
26.0.1. CI YAML, OpenAPI YAML and JSON schema fixtures parse and validate;
git diff --check passes.

Sandbox attempts initially failed on Gradle cache locks/sockets and Swift's
compiler cache. The recorded successful runs used approved access to these
resources. Early JDK 21 fallback runs are superseded by the Java 25 verification.

## Remaining verification limits

Remote CI and the exact Swift 6.2 compiler have not been run locally. CI is
configured to perform that check with the pinned Xcode selection. These results
cover the initial loopback backend slice, not device authentication, remote
access, SSE delivery, automatic retry deduplication or the full product roadmap.

## PR description

Implement the initial Blot backend and shared Swift contract slice. Projects,
runs, status changes, immutable specification revisions and tasks are invoked
through the application boundary and persisted atomically with SQLite outbox
events. Spring Boot exposes documented routes and typed errors; BlotDomain and
BlotAPI provide validated Codable models and command/event contracts.

Validation: projects, strict Gradle check/spotlessCheck and bootJar pass on JDK
25; 14 Java tests pass. Swift build/test passes with 2 domain and 10 API tests,
including decoding actual HTTP output. JSON schema/YAML validation and diff
whitespace checks pass. CI now transfers HTTP fixtures from Java to Swift.
Remote CI and exact Swift 6.2 execution remain to be observed; local Swift is 6.4.
