# Оболочка Blot и поведение питомца

Результат реализации оболочки по предоставленному референсу Codex. Проверка проведена на исходниках macOS приложения, без backend и Git операций.

## Единый масштаб — 13 октября 2026

Все маршруты Code/Work, каталоги, Motes и настройки используют общую оболочку. Ширина сайдбара сохраняется при смене экрана; настройки, открытые из чата, больше не сохраняют правую панель проекта. Общие `ContentColumn`, `PageContent` и `composerPlacement` задают ширину и отступы без отдельных правил для каждого экрана. Большие заголовки Home и пустого командного чата — regular 28 pt; заголовки страниц и каталогов — semibold 28 pt.

В `agent.pen` обновлены все 15 существующих окон macOS до 1312×751, общие компоненты панелей и поля ввода, настройки, каталоги, граф и встроенные примеры на листе питомца. Размеры сайта, iOS и больших листов спецификации сохранены. Сайдбары макетов используют размеры общего компонента без отдельных переопределений ширины.

### Проверки

- `scripts/check-macos-shell.sh --render` успешно выполнил модельные проверки, сборку BlotMac и матрицу 81 × 4 × 2. Подтверждены все 648 файлов и их реальные размеры Retina 2×.
- Матрица включает все 15 разделов настроек, три режима графа, Review/Terminal/Preview, Sources и ошибку чтения, вход/регистрацию/код, редакторы, меню модели/профиля, пустые списки, поиск без результатов и длинный текст.
- В живом приложении проверены переходы Home → Skills → Settings, сохранение ширины 256 pt между экранами, возврат к 240 pt, перетаскивание разделителя, поиск в палитре, стрелки и Escape, открытие и отмена редактора навыка, меню профиля, ввод и закрытие меню модели через Escape. Для меню модели добавлен явный клавиатурный фокус без рамки вокруг контейнера.
- Финальная сборка запущена через `./script/build_and_run.sh --verify`.

Диалоги в матрице используют реальные компоненты приложения поверх оболочки; отдельное открытие редактора навыка проверено нативным sheet. PNG показывают viewport прокручиваемого содержимого: длинные формы и списки доступны прокруткой. Рендеры не подтверждают системные диалоги удаления, файловый picker и непрерывность анимаций. Существующие восстановленные окна macOS сохраняют пользовательский размер; 1312×751 задаётся для нового окна.

Для сокращённой проверки:

```sh
BLOT_RENDER_SCREENS=home,skills,scheduled,settings-from-chat BLOT_RENDER_SIZES=1312x751 scripts/check-macos-shell.sh --render-only
```

## Реализовано

- Узкая навигация 52 pt, список проектов 240–320 pt, общий SwiftUI toolbar высотой 44 pt в оболочке окна. Системные кнопки окна остаются системными.
- Шрифты задаются явно: основной текст 14 pt, подписи 12 pt, заголовок сайдбара 20 pt, заголовок страницы 28 pt; множитель 1,15 удалён. Колонка чата — до 736 pt; строки списка 29 pt с промежутком 2 pt, основные кнопки 36 pt.
- Рамка 1 pt, скругление 14 pt, системная тень окна. Правая карточка проекта 264 pt с внешними отступами; на Home она изначально закрыта и доступна через кнопку верхней панели; раскрываемые Sources, Review и инспектор команды.
- История назад/вперёд восстанавливает режим, разговор, запуск и выбранный проект. Закрепления и добавленные Sources хранятся в памяти. Источники принимают локальные URL и просматриваются без отправки на сервер.
- Контекстная панель доступна на экранах проекта: Home, задача, New run, командный чат и граф. Skills и Scheduled заменяют список чатов в основном сайдбаре; центральная область показывает детали; настройки используют свою навигацию рядом с узкой панелью.
- Главный Blot 76 pt на пустом экране и 56 pt на краю поля ввода в разговоре; перемещение использует matchedGeometryEffect. Ролевые аватары сохраняют геометрию и аксессуары макета 18.
- Постановщик принимает часы, генератор случайных чисел и функцию ожидания. Четыре заданные сценки последовательно соединяют взгляды, наклоны, улыбки, потягивания, прыжки и подмигивания. Заметные реакции повторяются примерно каждые 7–9 секунд; между сценками паузы 0,8–1 секунды. Случайность меняет направление взгляда, но не порядок или темп. Активность сохраняется до сна, не затухает за первую минуту. Ввод, отправка, разрешение и ошибка адресуются конкретному чату или запуску.
- После пяти минут без взаимодействия — сон; ввод и клик будят питомца. Скрытие, неактивное окно и Reduce motion останавливают фоновые циклы. Завершённые ролевые реакции возвращаются к деликатному idle.

## Воспроизводимые проверки

Из корня репозитория:

```sh
scripts/check-macos-shell.sh
scripts/check-macos-shell.sh --render
scripts/check-macos-shell.sh --render-only
```

Первый запуск компилирует проверки против реальных исходников приложения. Второй дополнительно собирает macOS target и создаёт PNG через невидимые NSWindow/NSHostingView, используя ресурсы собранного приложения.

Рендеры используют `BlotWindowContent`, как и настоящий `WindowGroup`, включая `DockIconSync`. Общий `AppState` передаётся внешним модификатором всей композиции, чтобы вспомогательные background views тоже получали состояние. Это проверяет регрессию запуска с ошибкой «No Observable object of type AppState found».

Проверяются ветвление истории после Back, восстановление выбранного проекта, pin/unpin, отсутствие повторных Sources, изоляция событий по контекстам, создание запуска, пауза/возобновление команды и отдельных участников, Esc, отсутствие дубликатов при остановке, фильтр графа, интервалы, короткие паузы и порядок сценок при разных генераторах случайных чисел, сон/пробуждение, приоритет ошибки над вводом и отмена постановщика.

## Меню профиля

Карточка 228×242 pt открывается справа от аватара с привязкой к нижнему краю кнопки. Использует общий контроллер popup: Esc, клик снаружи и потеря активности закрывают карточку. Header открывает Account; Usage — Usage & billing с тем же локальным остатком. Show Pet открывает экран Blot в текущем режиме Code/Work и доступен по ⌥Space. Invite a friend открывает редактируемое приглашение с копированием; Help содержит Getting started, Keyboard shortcuts и About Blot; Log out использует существующий выход.

## Blot, Work/Code и Motes

Blot — главный агент с режимами Work и Code. Work открывает обычный разговор: без рабочей директории, ветки, команды и управления выполнением. История и черновики Work хранятся отдельно от задач Code и командных запусков. Code поддерживает одиночные задачи Blot и командные запуски Motes, включая граф, разрешения и инспектор участников. Motes доступны в навигации только в Code.

Scheduled показывает список расписаний в основном сайдбаре, Skills — список навыков, Motes — командные запуски, Blot — разговоры текущего режима. Возврат к Blot восстанавливает последний разговор. Названия иконок появляются справа от панели при наведении; используются общий компонент и одинаковое оформление.

Проверки включают изоляцию Work от команды, сохранение черновика после перехода в Scheduled и Back, возврат из Skills в разговор Blot, переход Code/Work и остановку Motes через Esc. Сборка и запуск доступны через `script/build_and_run.sh --verify`; кнопка Run использует тот же скрипт.

Для частичной повторной отрисовки:

```sh
BLOT_RENDER_SCREENS=scheduled,skills,work-chat,motes scripts/check-macos-shell.sh --render
```
