# Что подготовлено и проверено в Kiln

Дата: 11 октября 2026. Пользователь пишет код приложения, сервера и библиотек самостоятельно. Помощник отвечает за папки, документы, настройки и учёт подтверждённых результатов.

## Удаление добавленной реализации

Удалены Java-классы сервера, хранилища, провайдера и логгера; Swift-модели, сеть, граф и компонент оформления; их тесты; собственные Python- и shell-скрипты помощника. Тестовые targets и ссылки на пустые пакеты убраны из Xcode. Пользовательский исходный ContentView восстановлен. Сохранены разделение приложений Mac/iOS, ресурсы пользователя, минимум ОС 26 и общие схемы.

Старые результаты тестов удалённой реализации больше не служат основанием для текущих статусов. Отметки A2 «Выполнено» сняты. Удалённые исходники сохранены во временной резервной копии вне рабочего проекта, чтобы действие оставалось обратимым.

## Подготовка без кода приложения

Созданы папки платформ, Features, Models и Services, четыре пакета Swift с Sources и Tests, четыре модуля Java со стандартной структурой каталогов. Подготовлены Package.swift, Gradle Wrapper и зависимости, настройки форматирования, каталог версий, SHA-256, lock-файлы, OpenAPI, JSON Schema, двенадцать общих JSON-примеров и workflow CI. Заглушек реализации в этих папках нет.

## Статусы

Завершены десять документальных задач P0. Решение пользователя о минимуме macOS 26 / iOS 26 сохраняется. Каждая A2-задача содержит часть реализации или проверки кода и целиком остаётся открытой. Подготовленная часть указана в docs/README.md и документе соответствующей задачи. Все задачи S14 реализует пользователь. После проверки готового кода завершённая задача получит тег «Выполнено».

## Проверки

Сборка сайта проверяет заголовки и ID 22 документов задач, ссылки и JSON-примеры. Публикует 24 Markdown-файла и manifest с SHA-256. Настройки Gradle проверяются отдельно от исходников: отсутствие Java-классов не считается успешным тестом сервера. Пустые пакеты Swift не объявляются собираемыми библиотеками. Сборка стартовых приложений Xcode подтверждает настройку targets, а не готовность функций продукта.

GitHub CI, физические устройства, ОС 26, соединение с настоящим провайдером и подпись выпуска пока не объявляются проверенными. Документация отделяет эти проверки от готовых файлов настройки.
