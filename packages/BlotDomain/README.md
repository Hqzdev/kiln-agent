# BlotDomain

Пять неизменяемых типов Project, Run, SpecificationRevision, Task и RunStatus.
Пакет зависит только от Foundation и поддерживает Swift tools 6.2, macOS/iOS 26.

Инициализаторы и Codable decoding проверяют одинаковые инварианты: непустые строки,
абсолютный путь проекта, неотрицательную версию запуска, положительную ревизию,
непустые критерии и отсутствие зависимости задачи от самой себя. Строки обрезаются
по краям. Репозиторий представлен строкой пути без файловых операций.

Идентификаторы — UUID, даты — Date. Для обмена с Java используйте WireJSON из
BlotAPI: UTC ISO-8601 с опциональной дробной частью при чтении. Raw values статусов
совпадают с Java enum, неизвестные статусы отклоняются. UUID регистронезависимы.

Проверка: `swift test --package-path packages/BlotDomain`.
