# Kiln — landing

Next.js 16 · React 19 · Motion · без бэкенда.

```bash
npm install
npm run dev   # http://localhost:3000
```

Или двойной клик по `start.command`.

Страницы: `/`, `/features`, `/changelog`, `/beta`, `/workspace`.
Анимации — по motion-спеке из `agent.pen` (spotlight, nav pill, звуки, ⌘K и т.д.).
Звук включается/выключается кнопкой в навигации.

## Рабочая среда проекта

`/workspace` — визуальный план реализации Kiln: все 405 подзадач в 24 блоках,
50 подробных пакетов работ, фильтры, поиск по экранам и файлам, зависимости,
roadmap и полное ТЗ. Каталог показывает по 50 подзадач на странице.
Статусы и сроки плановые; сервер продукта Java/Swift здесь не реализуется.

Пакеты работ и roadmap редактируются в `lib/workspace/data.mjs`, полная спецификация —
в `lib/workspace/specification.mjs`. Файлы, результаты и проверки всех 405 подзадач
задаются в `lib/workspace/task-blueprints.mjs`; типы, сроки и зависимости собирает
`lib/workspace/task-catalog-builder.mjs`. После изменений выполните `npm run spec:generate`:
он обновит скачиваемый `public/KILN_TECHNICAL_SPECIFICATION.md`.
Команда `npm run build` также обновляет документ перед сборкой сайта.

Архитектурные документы: `docs/README.md` (22 MD и протокол проверки).
Пункт «Выполненные» в сайдбаре «Тип задачи» показывает девять завершённых
документальных задач; они исключены из «Всех задач» и списков типов.
Адрес `/workspace#completed` открывает этот пункт сайдбара.
Статусы и документы определяются в `lib/workspace/documentation.mjs`. Сборка
проверяет Markdown, ссылки и JSON-примеры, публикует MD и SHA-256 manifest.
На сайте документы доступны для чтения и скачивания через карточки задач.
