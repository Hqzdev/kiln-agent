# Архитектура: автоматическая сборка и проверки

Задача: A2.9. Дата: 11 октября 2026. Документ готов. Автоматические проверки продукта ещё нужно настроить.

CI — система, которая сама запускает сборку и тесты после изменения кода. Она должна сохранять реальные результаты каждого этапа.

## Этапы CI

| Этап | Среда | Что запускается | Что сохраняется |
| --- | --- | --- | --- |
| website | Node с зафиксированными зависимостями | npm ci, проверка документов, сборка сайта | Сборка и отчёт о полноте документов |
| java | JDK выбранной версии | Gradle Wrapper, форматирование, границы модулей, тесты отдельных частей и их совместной работы | Результаты тестов и файл сервера |
| swift-packages | macOS с выбранным Xcode | Проверка четырёх пакетов Swift | Результаты тестов и параметры сборки |
| macos-target | macOS | Общая схема, отладочная сборка и тесты | Приложение и результаты тестов интерфейса |
| ios-target | macOS с подходящим симулятором | Общая схема, сборка и тесты | Результаты сборки и тестов на симуляторе |
| release | Отдельный защищённый и разрешённый процесс выпуска | Подготовка принятой версии | Подписанные архивы, проверка Apple и контрольные суммы |

## Доступ и секреты

Проверки запроса на объединение кода (pull request) получают только необходимые данные. Ключ провайдера нельзя давать произвольному тестовому коду из недоверенной версии. Проверки с имитацией провайдера идут без настоящих секретов. Настоящий GigaChat проверяется отдельным явным запуском на доверенной машине с ограниченным бюджетом.

Ключи выпуска отделены от обычной сборки. CI не делает commit или push в main и не повышает права агента.

Кэш ускоряет работу, но не заменяет проверку сборки с нуля. Его ключ должен учитывать версии инструментов и файл фиксации зависимостей.

## Ошибки и пропущенные проверки

Падение теста, запрещённая зависимость и несовместимый формат данных означают отказ. Если симулятор отсутствует или процесс проверок не настроен, этап нельзя считать успешным. Проверка на симуляторе не подтверждает работу BLE или Wi-Fi на физических устройствах.

## Когда A2.9 можно закрыть

Нужно создать `.github/workflows/ci.yml` или согласованный аналог и реально запустить все этапы. Намеренная ошибка сборки и запрещённый импорт должны приводить к отказу. Чистая версия должна проходить. Наличие этого документа не подтверждает успешный запуск CI.
