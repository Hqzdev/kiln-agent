# Архитектура: приложения для Mac и iPhone

Задача: A2.2. Дата: 11 октября 2026. Документ готов. Проекты приложений ещё нужно создать и собрать.

В Xcode target — отдельная цель сборки, например приложение или набор тестов. Scheme — настройка, которая определяет, как эту цель собирать и запускать.

## Состав проектов

| Цель сборки | Проект и схема | Назначение |
| --- | --- | --- |
| KilnMac | apps/macos/KilnMac.xcodeproj / KilnMac | Интерфейс Mac, управление Java-процессом, Keychain, обнаружение по Bonjour и приём BLE-соединений |
| KilnIOS | apps/ios/KilnIOS.xcodeproj / KilnIOS | Клиент iPhone, QR-код, подключение по BLE, кэш и восстановление связи |
| KilnMacTests | Тот же проект macOS | Состояние интерфейса, работа процесса и системных сервисов |
| KilnMacUITests | Тот же проект macOS | Навигация, разрешения и доступность |
| KilnIOSTests | Тот же проект iOS | Подтверждения команд, состояние связи и кэш |
| KilnIOSUITests | Тот же проект iOS | Сопряжение, чат, граф и проверка результатов |

Предлагаемый минимум — macOS 14+ и iOS 17+. Его нужно подтвердить в P0.7. Команда разработчика для подписи и идентификаторы выпускаемых приложений выбираются при настройке учётной записи Apple. Пока они не считаются зарегистрированными.

## Запуск интерфейса

`KilnMacApp` создаёт окна (`WindowGroup`), настройки (`Settings`) и команды меню (`Commands`). В одном месте соединяются сервис управления Java, `BackendClient`, `EventStreamClient` и хранилище состояния проекта. Выбор в конкретном окне хранится отдельно от долговечных данных работы.

`KilnIOSApp` создаёт навигацию и сервис управления подключением. Без соединения пользователь сначала выбирает Mac и проходит сопряжение. Рабочая область открывается после проверки совместимости и получения полного состояния через проверенное подключение.

## Что относится только к одной платформе

`JavaProcessSupervisor`, интеграция с Keychain Mac и объявление BLE-сервиса находятся только в приложении macOS. В iOS нет среды Java, Git, shell или ключа провайдера. Общие модели и подготовка данных графа находятся в пакетах Swift.

Экран показывает состояние и отправляет команды. Он не решает, принята ли задача, разрешено ли действие Git, хватает ли бюджета и можно ли запустить инструмент. Эти решения принимает сервер.

## Сборка и системные разрешения

При подготовке поставки в пакет Mac добавляются совместимая среда Java и сервер. Открытие окна и выход из приложения требуют разных правил управления процессами.

Камера для QR-кода нужна только на iPhone. Запросы доступа к локальной сети и Bluetooth должны понятно объяснять их назначение.

## Когда A2.2 можно закрыть

Нужно создать `project.pbxproj`, общие схемы и тестовые цели. Оба приложения должны собираться из командной строки. Перед выбором симулятора проверяется список доступных устройств. Неизвестный ID устройства нельзя заранее записывать в скрипт сборки.
