# Blot: на каких устройствах должен работать продукт

Задача: P0.7. Дата: 11 октября 2026. Задача выполнена: пользователь утвердил macOS 26 и iOS 26 как минимальные версии. Проверки приложения на устройствах ещё предстоят.

## Утверждённые требования

| Часть продукта | Минимум | Что нужно проверить |
| --- | --- | --- |
| Интерфейс Mac | macOS 26+ | Сборка и запуск на самой старой поддерживаемой версии |
| Интерфейс iPhone | iOS 26+ | Сборка, установка на телефон, размер текста и возвращение из фона |
| Основная среда выполнения Mac | arm64, то есть Apple Silicon | Встроенная Java, Git, запуск программ, обнаружение по Bonjour и передача по BLE |
| Intel Mac | Поддержка пока не подтверждена | Отдельная среда Java x86_64, подпись и базовая проверка на устройстве |
| iPhone | Устройство с поддерживаемой iOS | Wi-Fi, Bluetooth Low Energy (BLE), сопряжение и смена соединения |

Минимальные версии первой поставки — macOS 26 и iOS 26. Это решение пользователя от 11 октября 2026. Более старые системы не поддерживаются. Для API из следующих версий нужен запасной вариант работы на версии 26 или отдельное решение о повышении минимума.

## Что уже известно

В исходной проверке рабочий компьютер сообщил через `sw_vers`: macOS 27.2, сборка 26B5101f. Команда `uname -m` вернула arm64. Эти сведения не подтверждают работу приложения на macOS 26. Модель Mac и конкретный физический iPhone в той проверке не определены.

В apps/Blot.xcodeproj настроены две цели с минимумом 26.0. Сохранён исходный пользовательский экран. Общие пакеты имеют настройки и папки, но исходники и тесты помощника удалены. Предыдущие проверки удалённого кода не подтверждают нынешнюю реализацию продукта. Установка на ОС 26 и связь физических устройств ещё не проверены.

## Проверки приложения перед поставкой

| Проверка | Где проверять | Текущее состояние |
| --- | --- | --- |
| Работа на macOS 26 | Подходящий Mac или согласованный стенд | Не проверено |
| Базовый запуск на текущей macOS | Рабочий Mac | Пользовательский стартовый экран; продукт ещё не реализован |
| Работа на iOS 26 | Подходящий симулятор и физический телефон | Не проверено |
| Сопряжение через Wi-Fi | Mac и iPhone в одной локальной сети | Не проверено |
| BLE: Mac принимает соединение, iPhone подключается | Физическая пара устройств | Не проверено |
| Переход iOS в фон и обратно | Физический iPhone | Не проверено |
| Установка без заранее установленной Java | Чистый Mac или новый пользователь | Не проверено |

Для каждой проверки нужно записать версию системы, архитектуру процессора, модель устройства без серийного номера, сборку приложения и фактический результат. Выбор минимальных версий в P0.7 уже завершён. Эта таблица описывает предстоящие проверки приложения, а не подтверждает их выполнение.

## Системные разрешения

Приложение должно понятно объяснять, зачем нужен доступ к локальной сети и Bluetooth. Камера нужна только на iPhone для считывания QR-кода. При отказе интерфейс объясняет ситуацию и предлагает ручное подключение, если оно возможно.

Для BLE используется [Core Bluetooth](https://developer.apple.com/documentation/corebluetooth). Возможность Mac принимать соединения и ограничения работы в фоне нужно проверить в NET-03 / B17.1. Наличие библиотеки само по себе этого не доказывает.
