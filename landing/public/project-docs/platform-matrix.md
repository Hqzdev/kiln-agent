# Kiln: на каких устройствах должен работать продукт

Задача: P0.7. Дата: 11 октября 2026. Документ готов, но устройства и совместимость ещё нужно проверить.

## Предлагаемые требования

| Часть продукта | Предлагаемый минимум | Что нужно проверить |
| --- | --- | --- |
| Интерфейс Mac | macOS 14+ | Сборка и запуск на самой старой поддерживаемой версии |
| Интерфейс iPhone | iOS 17+ | Сборка, установка на телефон, размер текста и возвращение из фона |
| Основная среда выполнения Mac | arm64, то есть Apple Silicon | Встроенная Java, Git, запуск программ, обнаружение по Bonjour и передача по BLE |
| Intel Mac | Поддержка пока не подтверждена | Отдельная среда Java x86_64, подпись и базовая проверка на устройстве |
| iPhone | Устройство с поддерживаемой iOS | Wi-Fi, Bluetooth Low Energy (BLE), сопряжение и смена соединения |

macOS 14 и iOS 17 пока являются предложением для первой версии. Если понадобятся более новые API, нужно предусмотреть работу на старой системе или пересмотреть минимум.

## Что уже известно

В исходной проверке рабочий компьютер сообщил через `sw_vers`: macOS 27.2, сборка 26B5101f. Команда `uname -m` вернула arm64. Эти сведения не подтверждают работу приложения на macOS 14. Модель Mac и конкретный физический iPhone в той проверке не определены.

Проекты Xcode и пакеты Swift продукта пока не созданы. Сборки приложений, установка на минимальной версии системы и Bluetooth-соединение пары устройств ещё не проверены.

## Что нужно сделать для завершения P0.7

| Проверка | Где проверять | Текущее состояние |
| --- | --- | --- |
| Работа на macOS 14 | Подходящий Mac или согласованный стенд | Не проверено |
| Базовый запуск на текущей macOS | Рабочий Mac | Приложение ещё не создано |
| Работа на iOS 17 | Подходящий симулятор и физический телефон | Не проверено |
| Сопряжение через Wi-Fi | Mac и iPhone в одной локальной сети | Не проверено |
| BLE: Mac принимает соединение, iPhone подключается | Физическая пара устройств | Не проверено |
| Переход iOS в фон и обратно | Физический iPhone | Не проверено |
| Установка без заранее установленной Java | Чистый Mac или новый пользователь | Не проверено |

Для каждой проверки нужно записать версию системы, архитектуру процессора, модель устройства без серийного номера, сборку приложения и фактический результат. После этого можно утвердить окончательный список поддерживаемых платформ и закрыть P0.7.

## Системные разрешения

Приложение должно понятно объяснять, зачем нужен доступ к локальной сети и Bluetooth. Камера нужна только на iPhone для считывания QR-кода. При отказе интерфейс объясняет ситуацию и предлагает ручное подключение, если оно возможно.

Для BLE используется [Core Bluetooth](https://developer.apple.com/documentation/corebluetooth). Возможность Mac принимать соединения и ограничения работы в фоне нужно проверить в NET-03 / B17.1. Наличие библиотеки само по себе этого не доказывает.
