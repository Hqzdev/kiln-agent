## Проверка файлов

Перед сборкой сайта проверяются все 22 документа задач: наличие главного заголовка и ID задачи, внутренние Markdown-ссылки и правильность JSON-примеров. Исходники копируются в публичную папку без изменений. Для каждого файла в список состава (`manifest`) записывается контрольный отпечаток SHA-256. В полном техническом задании обновляются статусы и ссылки.

## Что ещё открыто

P0.7 не завершён. Известны только macOS 27.2 и архитектура arm64 рабочего компьютера. Работа на минимальных версиях систем, конкретная пара Mac/iPhone и связь между ними ещё не проверены.

A2.1–12 не завершены. Документы подготовлены, но ещё нужны приложения, модули Java, настройки, схемы данных и их реальные проверки. В текущей рабочей папке Git-репозиторий продукта не создан. Приложения Swift/Java тоже ещё не созданы.

## Что означает «выполнено»

В список выполненных задач входят девять P0-задач, результатом которых являются готовые документы. Документ A2 — подготовленное описание будущей реализации. Его наличие не означает, что код написан или сборка прошла. Все 405 подзадач остаются в общем плане.
