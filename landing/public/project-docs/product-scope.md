# Blot: что входит в первую версию

Задача: P0.1. Версия документа: 1.1. Дата: 13 октября 2026.

Blot — ИИ-помощник с двумя режимами. В режиме **Work** это обычный ИИ-чат для вопросов и обсуждения. В режиме **Code** Blot превращается в инженерную команду: принимает задачу, планирует работу, привлекает специалистов и Motes — небольших агентов для узких задач — и работает с кодом проекта.

## Основные решения

Минимальные версии систем — macOS 26 и iOS 26. Более старые версии не поддерживаются.

- Главное приложение работает на macOS и написано на SwiftUI. Локальный сервер на Java поставляется вместе с приложением и своей средой выполнения: отдельно устанавливать Java не нужно.
- Клиент для iOS тоже написан на SwiftUI. Он передаёт команды Mac и показывает состояние проекта. Все инструменты и обращения к модели работают на компьютере.
- В первой версии используется GigaChat с личным API-доступом пользователя. Ключ хранится в защищённом хранилище Keychain на Mac.
- iPhone подключается через общую сеть Wi-Fi или Bluetooth Low Energy (BLE). Перед подключением устройства проходят сопряжение и проверку доверия.
- Темы и компоненты интерфейса берутся из `agent.pen`. Правила работы одинаковы на Mac и iPhone, расположение элементов зависит от размера экрана.
- Сервер запрещает изменения `main` и основной ветки удалённого репозитория. Сохранение коммита (commit) и отправка изменений (push) в рабочие ветки требуют разных разрешений.

## Ограничения первой версии

За конкретный проект отвечает один работающий Mac. Несколько доверенных клиентов могут наблюдать за ним. Совместное редактирование одного запуска с разных Mac не предусмотрено.

В обязательную поставку не входят подключение через интернет, облачный посредник, гарантированные фоновые уведомления, инструменты на iPhone и обучение собственной модели. Для GitHub и CI нужны отдельные компоненты с ограниченными правами. Базовая проверка использует локальный Git и разрешённую отправку изменений.

Mac должен быть доступен. Для GigaChat ему нужен интернет: Bluetooth только доставляет команды на компьютер. Интерфейс явно показывает сон Mac, отсутствие связи и ограничения фоновой работы iOS.

## После первой поставки

Отдельным этапом планируются подключения Gmail, Google Calendar и Google Drive. Пользователь сможет попросить Blot в Code найти письма с поручениями, сверить сроки с календарём, изучить выбранные документы и предложить список следующих действий. Первые версии интеграций будут только читать данные; создание задач Blot потребует принятия предложений пользователем, а запись и отправка данных в Google потребуют отдельного разрешения. Подробные scopes, сценарий и этапы описаны в [плане Google Workspace](integrations/google-workspace.md).

## Сроки и итоговая проверка

Плановый срок готовности функций — 1 декабря 2026. Со 2 по 14 декабря проходят аудит, исправление ошибок и повторные проверки. Передача проекта — 15 декабря. Дата сама по себе не подтверждает готовность.

Полный сценарий проверки: задание с iPhone → план → команда специалистов → вопрос коллеге → изменение на Mac → независимая проверка → исправление → проверка качества → просмотр изменений → разрешение на commit → разрешение на push. Дополнительно проверяются запрет изменений main, смена Wi-Fi/BLE и перезапуск Java.

## Что проверено в документе

REQ-01–18 охватывают обе платформы, модель, выполнение работы, безопасность, связь и поставку. Связи с экранами, API и задачами есть в [таблице проверки требований](acceptance-matrix.md). Минимальные версии утверждены в P0.7: macOS 26 и iOS 26. Доступные физические устройства ещё нужно подтвердить при проверках приложения.
