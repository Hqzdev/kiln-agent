# Blot: что инструменты могут делать на Mac

Задача: P0.8. Дата: 11 октября 2026.

## Инструменты первой версии

Имена в первом столбце — точные названия команд API. Они оставлены для разработчиков.

| Инструмент | Что получает | Что возвращает | Ограничение |
| --- | --- | --- | --- |
| project.read_file | projectId и проверенный фактический путь | Текст UTF-8 и сведения о файле | Только разрешённые папки; есть лимит размера |
| project.search | Запрос, папки и фильтры | Найденный текст с путями и строками | Только доступные папки |
| patch.prepare | Исходный коммит base SHA и предлагаемые изменения | Список изменений (diff) и контрольный отпечаток действия | Пока не меняет файлы |
| patch.apply | ID подготовленного изменения PreparedPatch | Копию состояния изменённых файлов | Нужны действующее разрешение и прежняя исходная версия |
| process.run | Программу, аргументы и рабочую папку | Код завершения и вывод с лимитом размера | Только проверенная среда с заданными ограничениями |
| git.prepare_commit | Ветку, подготовленные файлы и сообщение | Описание коммита PreparedCommit | Проверяются защищённые ссылки Git |
| git.commit | ID PreparedCommit | Номер коммита SHA | Нужен действующий допуск на commit |
| git.prepare_push | Удалённый репозиторий и полный refspec — описание передачи | Описание отправки PreparedPush | Проверяются все конечные ссылки |
| git.push | ID PreparedPush | Удалённую ссылку или статус «исход неизвестен» | Нужен отдельный допуск на push |
| artifact.read | ID результата и диапазон частей | Проверенное содержимое | Только свой проект; проверяются hash и лимиты |
| task.message | ID задачи, сессии, канала и текст | ID сообщения | Сообщение не даёт получателю новых прав |
| user.ask | ID запуска и блокировки, один вопрос и три варианта ответа | ID запроса; ответ поступает отдельным событием от пользователя | Оркестратор ждёт ответ и не продолжает зависящую от него работу |

Пути передаются отдельными полями, а не строкой shell, которой можно доверять без проверки. Аргументы проверяются по схеме. Неизвестный инструмент отклоняется.

## Вопрос пользователю и ожидание ответа

Если для безопасного или корректного продолжения ИИ не хватает решения пользователя, он создаёт запрос `user.ask` и приостанавливает запуск в состоянии `blocked`. Запрос показывается как опрос: один понятный вопрос и ровно три коротких варианта ответа. Варианты должны описывать доступные решения, а не подталкивать к заранее выбранному ответу.

В запросе сохраняются ID запуска и блокировки, формулировка вопроса, три варианта, причина остановки и условия возобновления. Ответ принимается отдельной командой доверенного клиентского приложения и связывается с ID запроса. Сам агент не может сформировать ответ за пользователя или снять блокировку.

Пока пользователь не ответил, ИИ не продолжает шаги, зависящие от этого решения, и не трактует молчание, тайм-аут, потерю соединения или доставку уведомления как ответ. После получения ответа система сохраняет выбранный вариант и инициатора, снимает блокировку и продолжает с остановленного шага. Если вопрос отменён или ответ требует нового разрешения, запуск остаётся заблокированным с обновлённой причиной.

Если вариантов недостаточно, опрос всё равно содержит три наиболее уместных выбора; формулировку можно уточнить так, чтобы пользователь мог указать иной ответ в доступном клиенте. Никакой вариант ответа сам по себе не выдаёт разрешение на commit, push или расширение доступа: такие разрешения проходят отдельную проверку.

## Запуск программ

Команды выполняются на Mac. iOS и посредник BLE передают их серверу Java. Они не запускают shell вместо сервера.

`process.run` не может обходить права других инструментов. Среда запуска ограничивает доступ к файлам, сети, переменным окружения и служебным данным Git.

У каждого процесса есть предельное время, лимит вывода, ограниченное окружение и отмена дочерних процессов. Секреты не передаются автоматически. Слишком длинный вывод обрезается с явной отметкой.

## Изоляция и доступ

Рабочие копии Git (`worktree`) разделяют файлы исполнителей, но служебные данные `.git` остаются общими. Прямое изменение ссылок, hooks, настроек Git и выход из разрешённых папок через символические ссылки запрещены независимо от инструкции модели.

Для Xcode нужен отдельный разрешённый профиль запуска. Сначала нужно проверить реальные ограничения на целевом Mac и описать доступ. До этого допустимы планирование, чтение и подготовка изменений. Наличие worktree не доказывает безопасность сборки.

Управление произвольными сторонними приложениями, доступ ко всему экрану и автоматизация через AppleScript не входят в начальный набор. Для них нужны отдельные права, разрешения и сценарии проверки.

## История действий

Запись `ToolOperation` содержит отправителя, задачу и попытку, commandId, hash подготовленного действия, время начала, состояние, код завершения и ID файла с выводом. Если исход неизвестен, перед повтором система выясняет, что действительно произошло.

## Как проверять ограничения

- Чтение за пределами разрешённой папки, в том числе через символическую ссылку, отклоняется.
- Если исходный base SHA изменился, подготовленное изменение не применяется автоматически.
- Shell не позволяет изменить main, скрыто выполнить push или прочитать секреты.
- По истечении времени процесс останавливается, частичный вывод сохраняется.
- Потеря BLE-соединения не меняет права и не создаёт вторую ToolOperation.

Реальное выполнение и изоляцию проверяют J6 / SEC-04. Этот документ определяет требования к инструментам.
