# Документация Kiln

Дата: 11 октября 2026. Здесь собраны 22 документа по задачам проекта, этот указатель и отчёт о проверке.

Kiln — приложение, в котором виртуальная команда помогает работать над кодом. Mac выполняет работу, а iPhone позволяет давать задания и следить за результатом.

## Как устроено приложение

```text
Приложение на Mac ── защищённое локальное соединение ── Java-сервер
Приложение на iPhone ── защищённое соединение по Wi-Fi ── Java-сервер
Приложение на iPhone ── Bluetooth ── посредник на Swift ── Java-сервер
Java-сервер ── планирование и выполнение задач ── основные правила проекта
            └─ база SQLite, GigaChat, Git, запуск команд и хранение результатов
```

Сервер на Java решает, какие действия разрешены, и выполняет их. Интерфейс на SwiftUI показывает состояние и передаёт команды. Ключ GigaChat и инструменты остаются на Mac. Независимо от способа подключения действуют одни правила доступа. Повторная доставка команды не должна запускать её второй раз.
