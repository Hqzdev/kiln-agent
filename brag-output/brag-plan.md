# Kiln — promo video plan

**What it is:** Kiln is a macOS coding agent that runs as a team. One orchestrator spins up role agents (engineer, designer, researcher, reviewer, QA, product, security) that hand work to each other in the open.

**Who it's for:** developers who want to hand off a whole feature, not just one prompt, and still see who did what.

**What sets it apart:** you get a visible team with roles, hand-offs and checks. A black-box single agent shows none of that. Every hand-off is a message you can open.

**Hook:** an amber spark in black. The Kiln mascot (arch + vertical eyes + ember mouth) rips past the camera, stops and stares.

**Angle:** "one intelligence, many specialists". The mascot changes into roles, the camera pulls back to reveal dozens of agents, they pass real messages, and the product UI assembles out of their work.

**Tone:** cinematic, restrained. Dark graphite with an amber accent. Mono for status, Inter for headlines. Kiln's own UI language: thin borders, small radii, no holograms.

**Punchline:** "One intelligence. Many specialists. One team." KILN · AI agent team · By Hqzdev.

**Share line:** see share-copy.txt.

## Storyboard (≈23.9 s, 30 fps, 1920×1080)

| # | Time | Scene | What happens |
|---|------|-------|--------------|
| 1 | 0.0–2.2 | Ignition | Amber glow fades in. The mascot flies out of the glow past the camera with a light trail and stops (micro-shake). KILN rises, then "AI agent team". Black → graphite. |
| 2 | 2.2–6.9 | One agent, many roles | Slow push-in. Voice: "I don't work alone. I build the team." The mascot turns in 3D: Engineer (hard hat assembles from segments) → Designer (beret, lighter amber) → Researcher (glasses, data fragments) → snaps back to Engineer. Voice: "I can be any role." |
| 3 | 6.9–10.3 | Reveal | Dolly-out with a wide orbit. ~70 agents materialize in a wave with role labels and tiny work screens. Data paths draw between them. Voice: "But I don't work alone." |
| 4 | 10.3–14.2 | The AI team | The camera flies through the crowd to five specialists. Pencil-style cards travel the lines: Research complete → Building the feature → Found an issue (amber) → Fixed (green) → Tests passed (progress). KILN / ORCHESTRATOR / ↓ / SPECIALIZED AGENTS assembles above. |
| 5 | 14.2–17.8 | Workspace | Whip-pan. Seven Kiln panels fly in on 3D diagonals: Project overview (anchor), Agent activity, Task progress, Code (typing), Research (streaming), QA (Running → Passed), Agent communication. Lines link them. |
| 6 | 17.8–20.1 | Everything connects | Panels collapse to centre. A light, bento-style layout like the site's home screen scales in: YOUR PROJECT / Built by AI agents. Counters keep moving. Dark → light. |
| 7 | 20.1–23.9 | Final shot | Flash match-cut to the Engineer in front of the team. KILN, then the slogan line by line, then AI agent team and By Hqzdev. Fade to black. |
